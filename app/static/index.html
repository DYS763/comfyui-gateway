最多 32768 字符；文本编码器单次上限 4096 token（约 3900 个中文字符），超出会被拒绝，请精简 caption/text/items。0 / 32768

使用说明

  • bbox_format 固定为 yxyx；bbox_coord_space 固定为 abs_centralized。
  • bbox 顺序为 [y_min, x_min, y_max, x_max]，以画布中心为原点；1024×1024 时范围是 -512~512。
  • label 只能是 object、character、text；text 元素必须填写 text。
  • 宽高不写在 JSON 里，使用上面的分辨率；修改分辨率后必须重新计算 bbox。
  • 不支持 weight、区域负向提示词；负向提示词请单独填写。最多 64 个 items（网关防御上限，官方节点不限数量；实际受 4096 token 预算约束），JSON 最多 32768 字符；每个 summary.caption、items[].caption、items[].text 最多 3900 字符；文本编码器单次上限 4096 token，超出会被拒绝，请精简 summary.caption、items[].caption/text、tags/palette 或减少 items。
  • 框是放置标注，不保证严格边界；建议文字框四周留出 padding。
